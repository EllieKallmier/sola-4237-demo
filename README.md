## Getting Started

### Installing

1. Download a copy or fork this repository to your local machine
2. [Install uv](https://docs.astral.sh/uv/getting-started/installation/) if you haven't already
3. Set up a virtual environment and add required packages by running the following code in your terminal:

    ```bash
    $ uv sync
    ```
